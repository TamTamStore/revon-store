# REVON Landing Page

صفحة هبوط عربية متجاوبة لبراند REVON.

## الملفات
- `index.html` الصفحة الرئيسية
- `style.css` التصميم
- `script.js` نموذج الطلب وواتساب
- `images/` صور المنتجات

## التشغيل محليًا
افتح `index.html` في المتصفح.

## النشر المجاني على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع جميع الملفات والمجلد `images`.
3. من Settings > Pages اختر النشر من Branch `main` وFolder `/root`.
4. احفظ، وسيظهر رابط الموقع.
